# 開通大量傷患系統權限

把「幫一個人開通 MCI 大量傷病患救護管理系統權限」這件事做成程式：
登入一次，整份名單一路做完，最後給你一份「誰成功、誰要自己補做」的清單。

程式做的就是你平常在做的那六步：

1. 登入系統
2. 點右上角的「OOO，你好」
3. 選「帳號子系統權限」
4. 選單位、填姓名、**把帳號關鍵字清成空白**，按搜尋
5. 對查到的那一位按「設定」
6. 把「MCI大量傷病患救護管理系統」設成「MCI002 縣市端使用者」，按確定

---

## 第一次使用（只要做一次）

1. 把 `.env.example` 複製成 `.env`（同一個資料夾）
2. 打開 `.env`，至少填好 **`MCI_ENTRY_URL`**（這個系統的登入頁網址）
3. 想省打字的話，順便填 `MCI_USERNAME` 與 `MCI_PASSWORD`

> ⚠ `.env` 不會進版控，也不會被打包進可攜版，帳密不會外流。
> 這是**另一個系統**的帳密，跟 `tools/ems-report/.env`（救護紀錄表查詢）完全分開。

---

## 平常怎麼用

雙擊 `捷徑\開通大量傷患系統權限.bat`，照著畫面做：

1. 黑視窗請你貼名單 → 從 Excel 複製「單位、姓名」兩欄整段貼上
   （**在黑視窗內按滑鼠右鍵就是貼上**，Ctrl+V 常被中文輸入法吃掉）
2. 貼完後在空白行再按一次 Enter
3. 瀏覽器會自己開起來、自己填好帳號密碼 → **你只要打驗證碼**，按登入
4. 剩下的它自己做，做完會列出結果，並在 `out/result/` 留一份清單

### 試跑與正式執行

| 做法 | 會發生什麼 |
| --- | --- |
| 直接跑（預設） | 每一位都走完六步，但**不按最後的「確定」**——系統不會被改動 |
| 加上 `--execute` | 真的按下確定；開始前會再問你一次 yes/no |

先試跑一次確認每一位都走得通，再用正式模式跑，是最省事的順序。

### 指令（不想用捷徑時）

```
npm run tool:mci -- grant                    試跑
npm run tool:mci -- grant --execute          真的開通
npm run tool:mci -- grant --file=名單.xlsx    從檔案讀名單（也吃 .csv／.txt）
npm run tool:mci -- grant --unit=大溪分隊      整份名單都用這個單位（名單只要寫姓名）
npm run tool:mci -- grant --limit=3          只做前 3 位
npm run tool:mci -- probe                    看看系統畫面現在長什麼樣（卡住時用）
```

任何指令都可以加 `--fresh-login`：不沿用上次的登入狀態，重新登入一次。

## 名單怎麼寫

一行一位，單位在前、姓名在後，中間用逗號、tab 或空白隔開都可以：

```
大溪分隊,測試甲
中壢分隊	測試乙
平鎮分隊 測試丙
```

- 從 Excel 複製兩欄貼上就是這個格式，不必自己整理
- 連標題列一起貼到也沒關係，程式認得出來並略過
- 重複的人只會做一次
- 單位名稱**寫得跟系統下拉選單一樣**最保險；只寫一部分也行，
  但如果同時符合兩個以上的選項（例如「測試乙分隊」與「測試乙分隊第二救護隊」），
  程式會停下來把候選列出來，不會亂猜

## 跑完之後

- 終端機會列出每一位的結果，姓名以 `王○○` 顯示
- `out/result/開通結果-日期時間.md` 是完整清單（**含姓名，請勿外傳**），30 天後自動刪除
- `out/last-run.log` 是完整執行過程，卡住時把它給我看就行，不必抄畫面

### 這些結果代表什麼

| 結果 | 意思 | 你要做什麼 |
| --- | --- | --- |
| 已開通 | 六步都做完，確定也按了 | 不用做什麼 |
| 試跑通過（未按確定） | 流程都走得通，但這次是試跑 | 加 `--execute` 再跑一次 |
| 查無此人 | 用這個單位＋姓名查不到人 | 確認單位對不對、姓名有沒有打錯 |
| 查到不只一人 | 同名同單位，程式不敢亂選 | 自己到系統點那一位 |
| 失敗 | 中途卡住（訊息會寫卡在哪一步） | 看訊息；系統改版的話跟我說 |

## 幾件刻意這樣設計的事

- **驗證碼一定要你本人打**：不做自動辨識、不接第三方辨識服務——那等於繞過人家系統的
  防自動化機制。代價只是每次開始時打一次；登入狀態會存 8 小時，同一天再跑通常免打。
- **看不懂就停手**：查到兩個人、單位符合兩個選項時一律不做，寧可你自己去點。
  幫錯的人開權限，比漏開嚴重得多。
- **預設不按確定**：這個工具會改別人的權限，所以要明確加 `--execute` 才會真的動手。
- **不上雲**：全程在這台電腦跑，名單與結果都不會傳到任何外部服務。
