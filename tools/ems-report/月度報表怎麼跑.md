# 月度報表怎麼跑（速查）

> 這一份是**給人看的操作備忘**，每次執行工具時會自動複製一份到 `out/report/`，
> 想不起來的時候直接在報表資料夾裡點開就好。
> 原始檔在 `tools/ems-report/月度報表怎麼跑.md`，要改內容請改那一份。

---

## 一、每個月要做的事（三步）

### 1. 跑之前，先確認兩張表都收齊了

| 表 | 給誰填 | 影響什麼 |
| --- | --- | --- |
| **增減試算表**（Google 試算表） | 各分隊填「有送醫但不該算未預警」的案件 | 每一列讓該分隊的**送醫案件數（分母）扣 1**，預警案件數不動 |
| **心電圖分隊申訴表**（Google 試算表） | 各分隊填「12 導程明明有在到院前傳出」的案件 | 補進心電圖的**分子**，配對不到的另補進分母 |

兩張表都是**跑的當下抓一次**，跑完才收到的填表不會算進去，要重跑。

### 2. 雙擊 `捷徑\月度報表輸出.bat`

- 會自己開瀏覽器到緊急救護管理系統，帳號密碼已代填。
- **只有一件事要你做：輸入驗證碼、按登入。** 驗證碼不做自動辨識。
- 登完就全自動，中途不用管它。

### 3. 等它跑完

| 報表 | 大約要多久 |
| --- | --- |
| 到院前預警比率 | 3~5 分鐘 |
| 12 導程心電圖到院前傳輸率 | **1~2 小時**（要一件一件開紀錄表核對上傳時間） |

前面那份失敗不會影響後面那份，結束時會列出每一份是完成還是失敗。
只想跑其中一份時用 `捷徑\救護預警統計.bat`（只跑預警那份）。

## 二、跑完會產出哪些檔

### `out/report/`　→　**可以發給分隊**

| 檔案 | 內容 |
| --- | --- |
| `YYYY-MM-到院前預警比率.xlsx` | 正式報表。分頁一依大隊排、分頁二依比率高低排 |
| `YYYY-MM-心電圖到院前傳輸率.xlsx` | 正式報表。版面同上 |
| `YYYY-MM-心電圖-有處置未勾選清冊.xlsx` | 有上傳 12 導程、但急救處置忘了勾 EKG檢查的案件。**提醒同仁記得點處置**用 |
| `YYYY-MM-心電圖待人工確認.xlsx` | 程式判不出到院前還到院後的案件（通常是 0 件，有才會產出） |

### `out/internal/`　→　**內部用，不要整份發給分隊**

| 檔案 | 內容 |
| --- | --- |
| `YYYY-MM-心電圖執行報告.md` | 這次跑出什麼、排除了哪些、申訴怎麼處理的。**要看結果先看這份** |
| `YYYY-MM-心電圖逐案判定.xlsx` | 心電圖分母裡的每一件，各自算在哪、依據是什麼 |
| `YYYY-MM-到院前未預警清冊.xlsx` | 送醫但沒有到院前預警的每一件，並標明分隊有沒有提報扣除 |

分隊來問「我那幾件是哪幾件」時，答案就在後兩份裡，**不需要重跑**。

> 產出檔只留最近三個月，更舊的下次執行時會自動刪掉。
> 系統匯出的原始明細（含個資）跑完就刪，要留請加 `--keep-raw`。

## 三、兩份報表的算法（被問到時照這個講）

### 到院前預警比率

```
分子 ＝ 該分隊「已結案 ＋ 送醫 ＋ 到院前傳送預警」的案件數
分母 ＝ 該分隊「已結案 ＋ 送醫」的案件數 － 增減試算表上該分隊當月的件數
```

- **扣除只動分母，不動分子。** 會被列在增減表上的案件，本來就不會是有預警的案件。
- 大隊的比率是**加權**算的（轄下分隊預警數總和 ÷ 送醫數總和），不是各分隊比率取平均。

### 12 導程心電圖到院前傳輸率

```
分母 ＝ 「有勾 EKG檢查」∪「有 12 導程心電圖」（同一件只算一次）－ OHCA 案件
分子 ＝ 分母中，12 導程的上傳時間早於到院時間者 ＋ 申訴補進來的
```

- 兩份查詢**互有出入**，所以取聯集；用任一邊當分母都會漏掉另一邊獨有的案件。
- **處置勾了 CPR ＝ OHCA**，分母分子都不算（OHCA 心電圖與 12 導程是兩回事）。
- 「有勾 EKG檢查、但系統裡沒有 12 導程」的案件**在分母裡，且不計入分子**——
  不是判成到院後，是根本沒東西可查。這是低分隊最常見的原因，看逐案判定表就分得出來。

## 四、常見狀況

| 狀況 | 怎麼辦 |
| --- | --- |
| 報表寫不出來，說檔案被鎖住 | Excel 開著同一個檔。關掉重跑，查詢結果不用重查 |
| 某分隊說數字不對 | 開 `out/internal/` 的逐案判定表或未預警清冊，一件一件對給他看 |
| 增減試算表讀不到 | `npm run tool:ems -- check-sheet` 檢查；多半是共用權限沒開成「知道連結的任何人／檢視者」 |
| 要補跑舊月份 | `npm run tool:ems -- monthly --month=2026-06` |
| 心電圖那份跑到一半斷了 | 進度有存檔，重跑會接著跑，不會從頭來 |
| 想先確認欄位有沒有抓對 | `npm run tool:ems -- ekg --limit=5` 只查核前 5 件 |

## 五、指令對照（不想用捷徑時）

```bash
npm run tool:ems -- monthly                  # 兩份一起做（＝月度報表輸出.bat）
npm run tool:ems -- run                      # 只做到院前預警比率
npm run tool:ems -- ekg                      # 只做心電圖傳輸率
npm run tool:ems -- <指令> --month=2026-06    # 指定月份
npm run tool:ems -- <指令> --keep-raw         # 保留系統匯出的原始明細（含個資）
npm run tool:ems -- check-sheet              # 檢查增減試算表讀不讀得到
```
