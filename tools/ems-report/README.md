# 救護紀錄表查詢工具（到院前預警比率統計）

自動登入「桃園市政府消防局緊急救護管理系統」的報表系統，查詢指定月份的救護紀錄，
匯出 Excel 後統計**各分隊的「到院前預警案件數 / 總案件數」比率**。

---

## 🔐 個資保護規範（本工具的第一原則）

系統匯出的 Excel 是**含個案明細的個人資料**。本工具的設計以「個資不外流」為前提：

| 規範 | 作法 |
| --- | --- |
| **不上雲** | 全程在本機執行。不寫入 Firebase、不呼叫任何外部 API、不上傳任何檔案。 |
| **原始明細用完即刪** | 系統匯出的 Excel 只落在 `out/raw/`，統計完成後自動刪除（要保留才加 `--keep-raw`）。 |
| **產出只有統計數字** | 最終報表僅含「分隊、案件數、預警數、比率」，不含任何個人欄位。 |
| **不進版控** | `tools/**/out/` 已列入 `.gitignore`，原始檔與報表都不會被 commit。 |
| **log 不印明細** | 終端機只顯示流程與筆數，不輸出個案內容。 |
| **探測模式不取資料** | `probe` 只記錄欄位／按鈕／下拉選項名稱，**不記錄任何表格資料列，也不截圖**。 |
| **驗證碼不自動破解** | 由使用者本人辨識輸入，不繞過系統的防自動化機制。 |
| **帳密不硬寫** | 只從本目錄的 `.env` 讀取（已 gitignore），且不得使用 `VITE_` 前綴。 |

> ⚠ 使用完請留意：`out/` 目錄若曾用 `--keep-raw` 保留原始檔，請自行確認是否已刪除，
> 並避免把該目錄放進會自動同步到雲端硬碟的路徑。

## 安裝

依賴已列在專案根目錄的 `package.json`，第一次使用執行一次即可：

```bash
npm install
```

使用本機已安裝的 Google Chrome，不會另外下載瀏覽器。

（選填）想省去每次打帳號密碼，把 `.env.example` 複製成 `.env` 並填入帳密：

```bash
cp tools/ems-report/.env.example tools/ems-report/.env
```

驗證碼仍需你本人輸入。

## 使用方式

```bash
# 探測頁面結構（開發／系統改版時用）
npm run tool:ems -- probe

# 跑完整流程：預設查「上個月 1 號 ~ 最後一天」
npm run tool:ems -- run

# 指定月份
npm run tool:ems -- run --month=2026-06

# 保留系統匯出的原始 Excel（含個資，慎用）
npm run tool:ems -- run --keep-raw
```

執行後會開啟 Chrome 視窗，**請在該視窗完成登入**（輸入驗證碼後按登入），
程式偵測到登入成功就會自動接手後續操作。

## 流程說明

1. 登入系統（帳密可代填，驗證碼人工輸入）
2. 左側選單 → 報表系統 → 救護紀錄表查詢
3. 設定查詢期間為指定月份的 1 號 ~ 最後一天
4. 急救處置進階搜尋 → 救護狀態＝「已結案」→ 查詢 → 匯出 Excel（**總案件數**）
5. 同上，再加上院前預警＝「到院前傳送預警」→ 查詢 → 匯出 Excel（**預警案件數**）
6. 本機解析兩份 Excel，依分隊彙總，產出比較表

彈出式視窗封鎖不需處理：自動化瀏覽器預設允許彈出視窗與檔案下載。

## 目錄結構

| 檔案 | 職責 |
| --- | --- |
| `config.mjs` | 網址、選擇器、查詢條件、路徑等設定（改行為先改這裡） |
| `dateRange.mjs` | 查詢期間計算（純函式） |
| `session.mjs` | 開瀏覽器、協助登入、等待登入完成 |
| `probe.mjs` | 頁面結構探測（只取結構，不取資料） |
| `logger.mjs` | 終端機輸出與帳號遮蔽 |
| `index.mjs` | CLI 進入點 |
