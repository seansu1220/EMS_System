# 緊急救護管理系統小工具

自動登入「桃園市政府消防局緊急救護管理系統」的報表系統，目前有三個功能：

| 功能 | 說明 |
| --- | --- |
| **到院前預警比率統計** | 查詢指定月份的救護紀錄，匯出 Excel 後統計各分隊的「到院前預警案件數 / 送醫案件數」比率 |
| **12 導程心電圖到院前傳輸率** | 分母＝有做 EKG 檢查的案件；分子＝做了 12 導程、**且逐案確認在到院前就傳出去**的案件 |
| **解鎖救護紀錄表** | 給一組 TEMSIS，自動找出該解哪一張並按下「調整為未結案」（預設仍是試跑） |

每個月的例行工作是 **`捷徑\月度報表輸出.bat`**：一次登入，把前兩份報表都做完。

---

## 🔐 個資保護規範（本工具的第一原則）

系統匯出的 Excel 是**含個案明細的個人資料**。本工具的設計以「個資不外流」為前提：

| 規範 | 作法 |
| --- | --- |
| **不上雲** | 全程在本機執行。不寫入 Firebase、不呼叫任何外部 API、不上傳任何檔案。 |
| **原始明細用完即刪** | 系統匯出的 Excel 只落在 `out/raw/`，統計完成後自動刪除（要保留才加 `--keep-raw`）。 |
| **產出只有統計數字** | 最終報表僅含「分隊、案件數、預警數、比率」，不含任何個人欄位。 |
| **不進版控** | `tools/**/out/` 已列入 `.gitignore`，原始檔與報表都不會被 commit。 |
| **log 不印明細** | 終端機只顯示流程與筆數，不輸出個案內容。 |
| **探測模式不取資料** | `probe` 只記錄欄位／按鈕／下拉選項名稱，**不記錄任何表格資料列，也不截圖**。 |
| **驗證碼不自動破解** | 由使用者本人辨識輸入，不繞過系統的防自動化機制。 |
| **帳密不硬寫** | 只從本目錄的 `.env` 讀取（已 gitignore），且不得使用 `VITE_` 前綴。 |

> ⚠ 使用完請留意：`out/` 目錄若曾用 `--keep-raw` 保留原始檔，請自行確認是否已刪除，
> 並避免把該目錄放進會自動同步到雲端硬碟的路徑。

## 安裝

依賴已列在專案根目錄的 `package.json`，第一次使用執行一次即可：

```bash
npm install
```

使用本機已安裝的 Google Chrome，不會另外下載瀏覽器。

（選填）想省去每次打帳號密碼，把 `.env.example` 複製成 `.env` 並填入帳密：

```bash
cp tools/ems-report/.env.example tools/ems-report/.env
```

驗證碼仍需你本人輸入。

## 使用方式

**一般使用請雙擊專案的 `捷徑` 資料夾內的批次檔，不需要打指令：**

| 捷徑 | 用途 |
| --- | --- |
| `捷徑\月度報表輸出.bat` | **每月例行**：預警比率 ＋ 心電圖傳輸率一次做完 |
| `捷徑\救護預警統計.bat` | 只要預警比率那一份時用 |
| `捷徑\解鎖救護紀錄表.bat` | 貼上 TEMSIS，找出該解哪一張紀錄表（試跑，不會真的解鎖） |
| `捷徑\正式解鎖救護紀錄表.bat` | 真的按下「調整為未結案」，結束時列出動過哪幾件 |
| `捷徑\設定登入帳密.bat` | 用記事本開啟 `.env` 填帳密，省去每次輸入 |
| `捷徑\不常用\心電圖傳輸統計-試跑5件.bat` | 只查核 5 件，確認判斷正確再跑整月 |
| `捷徑\不常用\救護預警統計-設定用.bat` | 頁面結構探測，系統改版時才用 |
| `捷徑\不常用\檢查增減試算表.bat` | 確認增減用的 Google 試算表讀不讀得到 |
| `捷徑\不常用\建立可攜版.bat` | 打包成隨身版，給不能安裝 Node.js 的電腦 |

指令列等價寫法：

```bash
# 月度報表：兩份一起做
npm run tool:ems -- monthly

# 只做到院前預警比率（預設查「上個月 1 號 ~ 最後一天」）
npm run tool:ems -- run

# 只做心電圖傳輸率
npm run tool:ems -- ekg
npm run tool:ems -- ekg --limit=5      # 只逐案查核前 5 件（先確認判斷正確）
npm run tool:ems -- ekg --no-verify    # 跳過逐案查核，只看原始件數（不是正式報表）

# 指定月份／保留系統匯出的原始 Excel（含個資，慎用）
npm run tool:ems -- monthly --month=2026-06
npm run tool:ems -- monthly --keep-raw

# 探測頁面結構（開發／系統改版時用）
npm run tool:ems -- probe

# 解鎖救護紀錄表（執行後貼上 TEMSIS，一行一個，空白行結束）
npm run tool:ems -- unlock
npm run tool:ems -- unlock --temsis=T115xxxx,T115yyyy
```

執行後會開啟瀏覽器視窗（本機的 Chrome，沒有就用 Edge），
**請在該視窗完成登入**（輸入驗證碼後按登入），程式偵測到登入成功就會自動接手後續操作。

## 解鎖救護紀錄表

**預設是試跑**：只告訴你「該解哪一張」，不會按下「調整為未結案」。
要真的解鎖請用 `捷徑\正式解鎖救護紀錄表.bat`（或加 `--execute`）——
解鎖不可復原，預設值就該站在安全的那一邊。
正式模式定位不明確的案件一律略過，結束時會單獨列出「這次到底動了哪幾件」。

自動流程（每筆 TEMSIS 各跑一輪）：

1. 救護紀錄表查詢，期間為**今天往回推兩個月**，填入 TEMSIS 查詢
2. 開啟該筆的救護紀錄表，讀出「救災救護指揮中心指派案號」
3. 案件列表，以派遣案號查詢，點「救護紀錄」進入案件
4. 只有一張紀錄表 → 那張就是目標；有多張 → **逐張比對 TEMSIS**，只認相符那一張
5. 比對不到就回報「需人工處理」，**絕不隨便挑一張**

個資保護：紀錄表**不下載、不截圖、不落檔**，全文只在記憶體中，讀完立刻關閉視窗；
畫面與紀錄檔上的編號一律只顯示末 4 碼。

## 12 導程心電圖到院前傳輸率（第一次跑請先試跑 5 件）

分母＝有做 **EKG 檢查**的案件；分子＝做了 **12 導程心電圖**、
而且**上傳時間早於到院時間**的案件。

系統的查詢只告訴你「有沒有做 12 導程」，不告訴你「什麼時候傳出去的」，
所以分子必須一件一件點開查核：讀到院時間 → 看傳輸紀錄（找不到就進案件內部看「上傳」）
→ 比較先後。**幾百件要跑一兩個小時。**

因此有這些保護：

- **每完成一件就存檔**：中途關掉視窗、當機、網路斷線都不必從頭跑，再執行一次會接著跑。
- **連續 5 件判定不出來就停**：畫面改版時每件都會失敗，早點停下來看錯誤訊息。
- **看不懂就不猜**：判定不出來的案件不計入分子，另外列成
  `out/report/心電圖待人工確認-YYYY-MM.xlsx` 交給你自己看。

> ⚠ 這個功能**還沒對實際系統跑過**（那兩個查詢欄位不在既有的探測結果裡）。
> 第一次請先雙擊 `捷徑\不常用\心電圖傳輸統計-試跑5件.bat`，
> 看畫面上的「到院時間」與「上傳時間」有沒有讀對，再跑整個月。
> 抓不到欄位時程式會中止並列出「這一頁實際有哪些欄位」，照著調 `config.mjs` 的 `EKG` 即可。

## 流程說明

**到院前預警比率**

1. 登入系統（帳密可代填，驗證碼人工輸入）
2. 左側選單 → 報表系統 → 救護紀錄表查詢
3. 設定查詢期間為指定月份的 1 號 ~ 最後一天
4. 救護狀態＝「已結案」、送醫情形＝「送醫」→ 查詢 → 匯出 Excel（**送醫案件數**）
5. 同上，再加上院前預警＝「到院前傳送預警」→ 查詢 → 匯出 Excel（**預警案件數**）
6. 本機解析兩份 Excel，依分隊彙總，產出比較表

**心電圖傳輸率**（查詢條件與上面**不同**：救護狀態與送醫情形都不限）

1. 同樣進到救護紀錄表查詢，只設查詢期間
2. 勾選「EKG檢查」→ 查詢 → 匯出 Excel（**分母**）
3. 取消勾選，心電圖下拉＝「12導程心電圖」→ 查詢 → 匯出 Excel（**分子候選**）
4. 逐案查核上傳時間是否早於到院時間，只有「到院前」才計入分子

彈出式視窗封鎖不需處理：自動化瀏覽器預設允許彈出視窗與檔案下載。

## 目錄結構

| 檔案 | 職責 |
| --- | --- |
| `config.mjs` | 網址、選擇器、查詢條件、路徑等設定（改行為先改這裡） |
| `dateRange.mjs` | 查詢期間計算（純函式） |
| `session.mjs` | 開瀏覽器、協助登入、等待登入完成 |
| `navigation.mjs` | frame 查找、選單導航、展開進階搜尋 |
| `formFill.mjs` | 表單填寫與**回讀驗證**、日期格式偵測 |
| `scrape.mjs` | 統計流程的查詢與兩次匯出 |
| `workbook.mjs`／`xlsxNode.mjs` | 匯出檔解析 |
| `aggregate.mjs`／`adjustSheet.mjs`／`report.mjs` | 分隊彙總、增減試算表、報表輸出 |
| `ekgScrape.mjs` | 心電圖流程的兩次查詢與匯出（定位 EKG 勾選框與心電圖下拉） |
| `ekgVerify.mjs` | 逐案查核上傳時間、進度存檔、待人工確認清單 |
| `timeParse.mjs` | 日期時間解析與先後比較（純函式） |
| `unlock.mjs` | 解鎖流程（查 TEMSIS → 讀案號 → 查案件 → 定位目標） |
| `caseFlow.mjs` | 解鎖與心電圖查核共用的案件層級頁面操作 |
| `pageFinder.mjs` | 以**畫面文字**定位欄位、按鈕、勾選框與下拉（不靠 id，改版較不易壞） |
| `recordSheet.mjs`／`pdfText.mjs`／`sheetFields.mjs` | 開啟紀錄表、PDF 轉文字、欄位擷取 |
| `probe.mjs` | 頁面結構探測（只取結構，不取資料） |
| `logger.mjs` | 終端機輸出與帳號遮蔽 |
| `index.mjs` | CLI 進入點 |
